# Кнопка «Поделиться местоположением» не отображает активное состояние после перезагрузки

**Описание:** После того как пользователь начал делиться местоположением и перезагрузил страницу, кнопка снова показывает «Поделиться местоположением» вместо «Остановить передачу». При этом геолокация в браузере всё ещё активна, и данные о местоположении продолжают отправляться.

**Шаги воспроизведения:**
1. Нажать «Поделиться местоположением»
2. Перезагрузить страницу (F5 / Cmd + R)
3. Кнопка показывает «Поделиться местоположением» (синий/неактивный вид)
4. Фактически геолокация всё ещё активна в браузере

**Ожидаемый результат:** При загрузке страницы нужно проверить, делится ли пользователь местоположением (`is_sharing_location = true` в БД), и если да — показать кнопку в состоянии «Остановить передачу» и возобновить watchPosition.

**Фактический результат:** `isSharing` в сторе сбрасывается на `false` при рестарте приложения.

**Возможная причина:** `isSharing` — локальное состояние Zustand, которое не восстанавливается из БД при инициализации. Нужно при загрузке проверять `user.is_sharing_location` и если true — автоматически запускать `startSharing()`.
