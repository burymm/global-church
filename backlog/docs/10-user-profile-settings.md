# Профиль пользователя

## Что нужно сделать

### 1. Меню настроек (в BottomNav)

Добавить 4-й пункт в навигацию или выпадающее меню рядом с BottomNav:

```
[🗺 Карта] [💬 Чат] [👤 Профиль] [⚙ Настройки ▼]
```

При нажатии на ⚙ появляется выпадающее меню с 2 пунктами:
- **Пользователь** — открывает страницу настроек профиля
- **Выйти** — разлогинивание (уже есть `signOut` в `authStore`)

### 2. Страница настроек профиля

**URL:** `/profile` (или `/settings/user`)

**Поля:**

#### А. Выбор иконки (аватар)
Выбор из набора эмодзи. Пользователь видит сетку эмодзи и выбирает одну.

Примеры эмодзи для православного контекста:
```
✝  ⛪  🙏  📖  🔥  💧  🕊  ⛪  🌟  ⚓  🎯  💡  🌿  ☀️  ❤️  🤝  👨  👨‍🦳  👳  🧔
```

При клике — эмодзи сохраняется в `user.icon` (или `display_icon`).

#### Б. Вереисповедание (denomination)
Уже есть в `ProfilePage`: Православный, Католик, Баптист, Пятидесятник, Харизмат, Другой.

#### В. Статусы (statuses / "Открыт для")
Мультивыбор из списка:
- Готов помолиться
- Готов пообщаться
- Ищу домашнюю группу
- Ищу друзей-христиан
- Открыт для разговора

Уже есть i18n ключи: `profile.statusesList.*`

### 3. Где хранить иконку

**Варианты:**
- Добавить поле `display_icon TEXT` в таблицу `users` (проще всего)
- Или использовать существующий `avatar_url` и показывать эмодзи вместо аватарки

**Рекомендуемый:** Добавить `display_icon` в БД — аватар (URL) остаётся для Google фото, а эмодзи — для отображения на карте.

### 4. Отображение на карте

Маркеры на карте показывают эмодзи вместо крестика (✝). Иконку рендерить в `userIcon()` функции `MapPage.tsx`.

### 5. Фикс: карта перекрывает нижнее меню

Лист карты (`MapContainer`) занимает всю высоту и залезает под BottomNav. Нужно добавить `padding-bottom` или `safe-bottom` класс контейнеру карты, чтобы контент не перекрывался навигацией.

### 6. Иконки для статусов

Сейчас статусы (readyToPray, openToTalk и т.д.) выводятся текстом. Нужно:

- Добавить каждому статусу свою иконку/эмодзи (например 🙏 — «Готов помолиться», 💬 — «Готов пообщаться», 🏠 — «Ищу домашнюю группу», 👫 — «Ищу друзей-христиан», 🗣 — «Открыт для разговора»)
- В настройках профиля показывать иконку слева от текста статуса
- На карте при клике на маркер в попапе показывать иконку + текст статуса

**Где хранить:** в i18n ключах добавить поле `icon` для каждого статуса, либо отдельный маппинг.
