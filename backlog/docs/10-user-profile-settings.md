# Профиль пользователя

## Что нужно сделать

### 1. Меню настроек (в BottomNav)

Выпадающее меню рядом с BottomNav при нажатии на ⚙:

```
[🗺 Карта] [💬 Чат] [👤 Профиль] [⚙ Меню ▼]
```

При нажатии на ⚙ появляется выпадающее меню с 2 пунктами:
- **Пользователь** — открывает `/profile` (та же страница, что и вкладка 👤 Профиль)
- **Выйти** — разлогинивание

### 2. Страница профиля (`/profile`)

Единая страница профиля, открывается как через вкладку 👤, так и через ⚙ → Пользователь.

**Поля:**

#### А. Выбор иконки (аватар)
Выбор из набора эмодзи. Пользователь видит сетку эмодзи и выбирает одну.

```
✝  ⛪  🙏  📖  🔥  💧  🕊  ⛪  🌟  ⚓  🎯  💡  🌿  ☀️  ❤️  🤝  👨  👨‍🦳  👳  🧔
```

При клике — эмодзи сохраняется в `display_icon`.

#### Б. Вереисповедание (denomination)
Православный, Католик, Баптист, Пятидесятник, Харизмат, Другой.

#### В. Статусы (statuses / "Открыт для")
Мультивыбор с иконками:
- 🙏 Готов помолиться
- 💬 Готов пообщаться
- 🏠 Ищу домашнюю группу
- 👫 Ищу друзей-христиан

#### Г. Интересы
Мультивыбор: Помолиться, Изучить Библию, Найти домашнюю группу, Посетить службу, Общение, Наставничество.

#### Д. Язык
Выбор из 3: Русский, Беларуская, English.

#### Е. Имя
Текстовое поле.

### 3. Хранение иконки

Поле `display_icon TEXT` в таблице `users`.

### 4. Отображение на карте

Маркеры на карте показывают выбранную эмодзи. Иконка рендерится в `userIcon()` в `MapPage.tsx`.

### 5. Иконки для статусов

Каждый статус имеет свою иконку/эмодзи, которая показывается слева от текста в настройках профиля и в попапе на карте.

Маппинг: `statusIcons` экспортируется из `src/i18n/index.ts`.
