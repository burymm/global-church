# Roadmap

## Фаза 1 — MVP (первая версия)

**Цель:** Запустить работающее приложение в Минске.

### Что входит

- Google OAuth авторизация
- Полноэкранная карта (Leaflet + OpenStreetMap) с маркерами пользователей
- Точная GPS-геолокация с периодической отправкой
- Включение/выключение передачи координат
- Личные сообщения (direct chat) через Supabase Realtime
- Профиль: имя, аватар, конфессия, тип веры, интересы, статусы, язык
- PWA (Add to Home Screen)
- 3 языка: русский, белорусский, английский
- Row Level Security (RLS) на все таблицы
- Mobile-first UI

### Критерии готовности

- Можно открыть на телефоне, зайти через Google, включить геолокацию и увидеть маркер на карте
- Можно открыть чат с другого аккаунта и отправить сообщение
- Работает "Add to Home Screen" на iOS и Android
- Деплой на Vercel

### Dev Tools для AI-агентов (MCP)

Настройка инструментов, чтобы AI-агент мог видеть и проверять результат своего кода:

- [x] **chrome-devtools-mcp** — агент открывает браузер, делает скриншоты, проверяет console errors
  ```
  claude mcp add chrome-devtools --scope user npx chrome-devtools-mcp@latest
  ```
- [x] **context7** — документация React/Vite/Supabase в контексте агента
  ```
  claude mcp add context7 --scope user npx @upstash/context7-mcp@latest
  ```
- [x] **Playwright** — встроен в Claude Code, отдельный MCP не нужен. Агент может использовать встроенные инструменты для UI тестирования
- [x] Проверить: агент пишет компонент → открывает браузер → видит как выглядит → исправляет

**Зачем:** Убирает цикл "написать → показать → ждать фидбек → исправить". Агент сам себя проверяет.

## Фаза 2 — Улучшение UX

**Цель:** Улучшить пользовательский опыт после первых отзывов.

### Что добавить

- Статус "онлайн/оффлайн" с авто-определением
- Настраиваемый интервал heartbeat (по умолчанию 1 мин) — в настройках профиля
- Настраиваемый таймаут оффлайн (по умолчанию 3 мин) — в настройках профиля
- Кластеризация маркеров (когда много людей вместе — показывать "12" вместо кучи точек)
- Анимация движения маркера (плавное перемещение)
- Фильтр по карте: показать только тех, кто "готов помолиться" / "ищет домашнюю группу"
- Бейджи статусов на маркерах
- Уведомления о новых сообщениях (Web Push — бесплатно)
- Автоопределение языка браузера
- Полное покрытие i18n — все тексты вынесены в переводы (без хардкода)
- Экран "Нет пользователей рядом" с подсказкой

### Что улучшить

- Производительность карты при 100+ маркерах
- Loading states и skeleton screens
- Offline fallback (кэшированная карта, "Вы оффлайн")

### Dev Tools расширение

- [ ] Playwright E2E тесты для критических flow (авторизация, отправка сообщения)
- [ ] Lighthouse CI — агент проверяет Core Web Vitals до деплоя
- [ ] Алертинг через MCP — агент мониторит продакшн логи

## Фаза 3 — Масштабирование на Беларусь

**Цель:** Запуск по всей Беларуси.

### Что добавить

- Возможность указать город вручную (без GPS)
- Групповые чаты (домашние группы, молитвенные кружки)
- Объявления ("Собираемся на службу в воскресенье в 10:00")
- Поиск пользователей по имени / конфессии / интересам
- "Ближайшие церкви" — статические точки на карте (адреса, время служб)
- Модерация и жалобы на пользователей

### Что улучшить

- Paginated infinite scroll для чатов
- Оптимизация запросов (меньше данных при загрузке)
- Метрики и аналитика (Plausible — open source, бесплатно)
- Документация и onboarding для новых пользователей

### Контейнеризация (Docker)

- [ ] Создать `Dockerfile` для фронтенда (Vite build → nginx)
- [ ] Создать `Dockerfile` для бэкенда (Node.js — замена Supabase)
- [ ] Создать `docker-compose.yml` с тремя сервисами:
  - `frontend` — nginx, раздаёт статический фронт
  - `backend` — Node.js/Express, REST API + WebSocket
  - `db` — PostgreSQL (или переезд с Supabase Cloud на self-hosted Postgres)
- [ ] Настроить CI/CD: GitHub Actions → `docker build` → `docker compose up`
- [ ] Деплой на свой сервер (i9-14900K, 64GB RAM)
- [ ] Nginx reverse proxy + Let's Encrypt (HTTPS)

## Фаза 4 — Полноценная платформа

**Цель:** Глобальный запуск, рост до десятков тысяч пользователей.

### Что добавить

- Другие соцсети для авторизации (Apple, Telegram)
- Групповые чаты с файлами и голосовыми
- События / встречи ("Воскресная встреча, адрес X, время Y")
- Пуш-уведомления (Firebase / Web Push)
- Админ-панель (управление пользователями, модерация)
- Verification бейджи (проверенный пользователь)
- Статистика и аналитика для админов
- Dark mode

### Инфраструктура

- Supabase Pro ($25/мес)
- Cloudflare CDN
- Мониторинг и алерты
- Backup strategy
