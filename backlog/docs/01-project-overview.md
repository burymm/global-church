# Global Church — Встречи христиан

## Описание

Мобильное PWA-приложение для знакомства и общения христиан. Пользователи видят друг друга на карте, указывают свои интересы и статусы, отправляют личные сообщения.

## Цели

- Помочь людям найти единомышленников для молитвы, общения, изучения Библии
- Создать пространство открытое как для христиан, так и для людей других убеждений
- Запустить локально (Минск), масштабировать на Беларусь и весь мир

## Целевая аудитория

- Христиане разных конфессий (православные, католики, баптисты, пятидесятники, харизматы)
- Люди других религий и атеисты, желающие пообщаться с христианами
- Люди ищущие домашнюю группу, молитвенных партнёров, друзей

## Функциональность (v1)

### Авторизация
- Google OAuth (через Supabase Auth)
- Без хранения логина/пароля
- Автоматическое создание профиля при входе

### Карта и геолокация
- Полноэкранная карта с маркерами пользователей
- Маркеры показывают местоположение людей, которые делятся геолокацией
- Когда много людей вместе — каждый маркер виден отдельно (кластеризация на будущее)
- Источник координат: точная GPS-геолокация телефона
- Обновление координат: периодическое (каждые 10-30 сек)
- Пользователь включает/выключает передачу сам
- В будущем: возможность указать местоположение вручную (город, конкретная церковь)

### Профиль
- **Отображаемое имя** (из Google или кастомное)
- **Аватар** (из Google)
- **Конфессия**: православный, католик, баптист, пятидесятник, харизмат, другой
- **Тип веры**: христианство / другая (мусульмане, атеисты и т.д.)
- **Интересы** (множественный выбор):
  - Помолиться
  - Изучить Библию
  - Найти домашнюю группу
  - Посетить церковную службу
  - Общение
  - Наставничество
- **Статусы** (множественный выбор):
  - Готов помолиться
  - Готов пообщаться
  - Ищу домашнюю группу
  - Ищу друзей-христиан
  - Открыт для разговора
- **Язык**: русский, белорусский, английский

### Чат
- Личные сообщения (direct messages)
- Групповые чаты — не в первой версии
- Сообщения доставляются при следующем входе в приложение (не обязательно мгновенно)
- Supabase Realtime для получения новых сообщений в реальном времени
- Начало разговора: нажатие на пользователя на карте → открывается чат
- Возможность запретить конкретному пользователю писать (блок)

### PWA
- Add to Home Screen на iOS и Android
- Работа как standalone-приложение (без браузера)
- Service Worker для кэширования
- Без публикации в App Store / Google Play
