# Кластеризация пользователей на карте (иконка церкви)

## Идея

Когда несколько христиан собираются вместе в одном месте (радиус ~20 метров), на карте вместо их отдельных маркеров показывать **иконку церкви ⛪ с количеством человек**. При клике на иконку — раскрываются все пользователи в этом месте.

Это позволит тем, кто ищет церковь/домашнюю группу, увидеть, где собираются верующие, и присоединиться.

## Пример отображения

```
                 ⛪ 3
                  ↓
          ┌──────────────┐
          │ 🙏 Анна       │
          │ 💬 Пётр       │
          │ 📖 Иван       │
          └──────────────┘
```

## Что нужно сделать

### 1. Определение групп (backend-логика)

Группировать пользователей по координатам:
- Если расстояние между пользователями <= 20 метров — они в одной группе
- Центр группы = среднее арифметическое координат всех участников
- Участник может быть показан как часть группы или отдельно (если >20м от всех)

Алгоритм:
- Пройти по всем `userLocations`
- Для каждого найти ближайших в радиусе 20м
- Собрать в группы (кластеры)
- Группа отображается как ⛪ + количество

### 2. Отображение на карте

В `MapPage.tsx`:
- Вместо прямого рендера `userLocations.map(...)` сначала группировать
- Для одиночных пользователей (>20м от других) — обычный маркер (как сейчас)
- Для групп (2+ человека рядом) — **divIcon** с ⛪ и числом
- При клике на группу — показать Popup со списком участников (аватар/иконка + имя + статус)

### 3. Вычисление расстояния

```typescript
function haversineDistance(lat1: number, lng1: number, lat2: number, lng2: number): number {
  const R = 6371000; // Earth radius in meters
  const toRad = (deg: number) => (deg * Math.PI) / 180;
  const dLat = toRad(lat2 - lat1);
  const dLng = toRad(lng2 - lng1);
  const a = Math.sin(dLat / 2) ** 2 +
            Math.cos(toRad(lat1)) * Math.cos(toRad(lat2)) * Math.sin(dLng / 2) ** 2;
  return R * 2 * Math.atan2(Math.sqrt(a), Math.sqrt(1 - a));
}
```

### 4. Обновление в реальном времени

Группы пересчитывать при каждом `fetchOnlineLocations` (каждые 30с) — не нужно дополнительных запросов.

## UI/UX нота

- **Одиночный пользователь:** обычная круглая иконка (как сейчас)
- **Группа 2+:** ⛪ в кружке, рядом число. Цвет — тёплый (оранжевый/золотой), чтобы выделялся
- **Popup группы:** список участников, каждый с иконкой и именем. При клике на участника — открывается чат (как сейчас при клике на одиночный маркер)
