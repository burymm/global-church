# task-05 — Улучшение UI попапа на карте

## Описание
Два улучшения для попапа пользователя на карте:

1. **Отображение имени**: если `display_name` пустой (пользователь очистил поле в настройках), показывать оригинальное имя из Google аккаунта (которое было установлено при регистрации через `handle_new_user` триггер).
2. **Статусы только иконками**: в попапе убрать текстовые лейблы статусов, оставить только иконки (emoji) в одну строку.

## Изменения

### 1. Сохранение оригинального имени (БД)
- Добавить колонку `auth_name TEXT` в таблицу `users`
- В триггере `handle_new_user` сохранять `raw_user_meta_data->>'full_name'` (или email) в `auth_name`
- `display_name` остаётся изменяемым пользователем полем

### 2. MapPage.tsx — `PopupContent` и `GroupPopupContent`
- `{loc.statuses.map((s) => statusIcons[s]).join(' ')}` — только иконки, без `i18n.t()`
- Убрать класс `truncate`, если нужно
- В одной строке (flex row)

### 3. MapPage.tsx — fallback имени
- `{loc.display_name || loc.auth_name || 'User'}` — показывать `display_name`, если пусто — `auth_name`

### 4. ProfilePopup.tsx (опционально)
- Можно подсказывать пользователю оригинальное имя, если он очистил поле
