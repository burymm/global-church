# task-02 — Счётчик непрочитанных + автообновление списка чатов

## Описание
1. Показывать количество непрочитанных сообщений на иконке чата в BottomNav и в списке чатов.
2. При отправке/получении нового сообщения — список чатов (conversations) должен обновляться автоматически: новый диалог появляется, у существующего подтягивается последнее сообщение и время.

**Проблема:** Сейчас после отправки сообщения новому человеку, если выйти в список чатов — диалог там не отображается. Нужно сходить на карту и вернуться, чтобы `fetchConversations` сработал.

**Без изменений в БД** — всё на клиенте.

## Изменения

### Типы
- Conversation: добавить `unread_count: number`

### chatStore.ts
- `sendMessage` — после успешной отправки локально создать/обновить запись в `conversations` (добавить диалог с `last_message`, `last_message_at`, `other_user` если новый)
- Realtime: при получении нового сообщения от собеседника — обновить `conversations` (добавить диалог или обновить `last_message`/`last_message_at`), и увеличить `unread_count` если чат не активен
- `setActiveUser` — при открытии чата сбросить `unread_count` для этого диалога
- `fetchMessages` — подсчитать unread по загруженным сообщениям
- Вычислять `totalUnread` как сумму всех `unread_count` по conversations (getter)

### ChatPage.tsx
- В списке чатов рядом с диалогом показывать бейдж `(N)` если `unread_count > 0`
- `pb-20` -> `pb-16` если есть бейдж (или другая правка отступа)

### BottomNav.tsx
- На иконке чата показывать бейдж-круг с числом если `totalUnread > 0` (стиль как у iOS: red circle, white text, top-right)

### i18n
- Ключи не нужны
